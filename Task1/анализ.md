| **Тип данных**      | Данные, которые получает клиент при просмотре информации о витрине, онлайн туру, общедоступная информация на сайте, реклама и объявления, пресс-релизы, новости, заявления, публичные отчёты, общая информация о компании. Данные не должны никак влиять на внутреннюю структуру компании и каким-либо образом компрометировать как компанию, так и других клиентов | Сами по себе данные не являются строго конфиденциальными, однако не предназначены для публичного доступа. К таким данным могут относиться: логи работы систем, служебная переписка, внутренние инструкции/политики, ряд отчётов, журналы аудита, какая-либо внутренняя аналитика/KPI, данные о зп, описание товаров и услуг                                                                                                                                                                                                               | Информация, которая не должна попасть в третьи руки, т.к. в ином случае это может нанести ущерб организации, клиентам и партнёрам. К таким данным можно отнести: персональные данные клиентов и сотрудников компании, финансовая информация, платёжные документы, информация о взаиморасчётах с партнёрами, комерческая тайна                           | Информация, раскрытие которой может привести к самым серьёзным последствиям для организации. К таким данным можно отнести: критичная коммерческая тайна (планы о слиянии с другой компанией), api ключи/параметры каналов связи для вызова государственных сервисов                                                                                                 |
| **Риски**           | Для публичных данных есть риски некачественных данных, т.к. приведение этих данные в "некачественное", отличное от целевого состояние может привести к финансовым потерям из-за оттока клиентов.                                                                                                                                               | Для внутренних данных есть следующие риски: утечка данных (сотрудник может отправить служебное письмо внешнему лицу), потеря данных (логи/аудит могут быть удалены из-за неправильной конфигурации), искажение данных (намеренное изменение данных в отчёте для повышенной премии по итогам KPI), некачественные данные (некорретно настроенные метрики/отчёты могут дать неправильное понимание того, нужно ли менять/создавать/изменять новый продукт или услугу)                                                                       | Утечка данных (кража клиентской базы, отправка фин. отчёта внешнему лицу), потеря данных (удаление базы данных клиентов), искажение данных (изменение параметров продаваемого объекта)                                                                                                                                                                 | Утечка данных (передача документов по подготовке слияния компаний третьему лицу, хакерская атака с последующей утечкой данных для подключения к гос. сервисам), потеря данных (взлом, кража и удаление ключа шифрования), искажение данных (изменение отчётов при подготовке слияния, которые влияют на стоимость компании)                                          |
| **Оценка риска**    | Некачественные данные - Незначительный риск.                                                                                                                                                                                                                                                                                                     | утечка данных, искажение данных, некачественные данные - Значительный риск; потеря данных - незначительный                                                                                                                                                                                                                                                                                                                                                                                                                                 | Утечка данных, потеря данных, искажение данных - критичный риск                                                                                                                                                                                                                                                                                          | Утечка данных, потеря данных, искажение данных - максимально критичный риск                                                                                                                                                                                                                                                                                         |
